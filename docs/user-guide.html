BL Crop Raid Report — User Guide

This guide walks you through configuring and running the Big Life Crop Raid Report workflow, which ingests human-wildlife conflict crop raid events from EarthRanger and produces a comprehensive incident analysis report and dashboard for the Amboseli ecosystem.

What it produces

  • Charts — time-of-day incident distribution, damage size boxplot by ranger response timing, monthly incidents by crop raid location, crop species pie charts (by count and by area), and monthly incidents/damage stacked bars
  • Maps — a crop raid density grid, a timing-of-ranger-response scatter map, a species-responsible scatter map, and a per-month crop-destroyed scatter map (one view per month)
  • Summary tables — elephant damage by month, mean elephant group size, ranger response timing with percentages, total acres damaged, species damage, and crop damage (6 GeoParquet tables)
  • A Word document report (overall_report.docx) — every chart, map, and table assembled into the Big Life crop raid report template, downloaded automatically from Dropbox
  • An interactive dashboard — 17 widgets covering every chart, map, and table produced by the run (the per-month crop maps are merged into a single switchable widget)

The three Amboseli geospatial layers and the Word report template are downloaded automatically from Dropbox at run time.

Requirements

  • Access to an EarthRanger instance with hwc_crop_raids events logged for the analysis period

1. Load the Workflow

In the workflow runner, go to Workflow Templates and click Add Workflow Template. Paste this repository's URL into the Github Link field, then click Add Template:

https://github.com/wildlife-dynamics/bl_crop_raid_report.git

Once added, it appears in the Workflow Templates list as bl_crop_raid_report. Click the card to open the workflow configuration form. The card may show Initializing… briefly while the environment is set up.

2. Configure the Workflow

EarthRanger Connection

Navigate to Data Sources and click Connect, then select EarthRanger. Fill in the connection form:

FieldDescription
Data Source NameA label to identify this connection
EarthRanger URLYour instance URL (e.g. your-site.pamdas.org)
EarthRanger UsernameYour EarthRanger username
EarthRanger PasswordYour EarthRanger password

Credentials are not validated at setup time. Any authentication errors will appear when the workflow runs. Click Connect to save.

All crop raid events are fetched within this window. Monthly breakdowns in the charts, tables, and maps are derived from the event timestamps within this range.

Once all sections are filled, click Submit.

3. Run the Workflow

Once submitted, the runner will:

  1. Download the Amboseli land-use, ranch boundary, and electric fence layers from Dropbox and reproject them to EPSG:4326.
  2. Fetch hwc_crop_raids events from EarthRanger for the specified time range.
  3. Process and normalise event details (field titles, numeric conversions, 3-hour time bins).
  4. Generate all 7 charts and persist as HTML and PNG.
  5. Generate the density grid map, timing-of-response map, species map, and a per-month crop-destroyed map (one view per month).
  6. Compute 6 summary tables and persist as GeoParquet files.
  7. Download the Big Life crop raid Word template from Dropbox and populate it with all charts, maps, and tables.
  8. Assemble the 17-widget dashboard.
  9. Save all files to the directory specified by ECOSCOPE_WORKFLOWS_RESULTS.
