Technical Guide

A deeper look at how the BL Crop Raid Report workflow is built: the event pipeline, every chart, map, and table, and Word report and dashboard generation.

Download the full Technical Guide (PDF) v2.0

Version 2.0 rewrites the guide against the current spec.yaml (id crop_raid_report). It corrects the dependency list (migrated to ecoscope-platform plus the Big Life, WWF-Virunga, STE, MNC, and custom extension packages actually declared), the real task names (several in the previous version matched nothing in spec.yaml), the Word report's fixed "Ecoscope" author field and overall_report.docx filename, and the dashboard, which wires up 17 widgets. It also documents two quirks found in the current spec: the “French beans” colour value not appearing in the top-crops chart's stack order, and the “Acres”-labelled damage chart not actually being filtered to acre-measured events.
