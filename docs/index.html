BL Crop Raid Report

Ingests human-wildlife conflict crop raid events from EarthRanger and produces a comprehensive incident analysis report and dashboard for the Amboseli ecosystem.

What it produces

  • Charts — time-of-day incident distribution, damage size boxplot by ranger response timing, monthly incidents by crop raid location, crop species pie charts (by count and by area), and monthly incidents/damage stacked bars
  • Maps — a crop raid density grid, a timing-of-ranger-response scatter map, a species-responsible scatter map, and a per-month crop-destroyed scatter map
  • Summary tables — elephant damage by month, mean elephant group size, ranger response timing with percentages, total acres damaged, species damage, and crop damage (6 GeoParquet tables)
  • A Word document report (overall_report.docx) — every chart, map, and table assembled into the Big Life crop raid report template
  • An interactive dashboard — 17 widgets covering every chart, map, and table produced by the run

Requirements

  • Access to an EarthRanger instance with hwc_crop_raids events logged for the analysis period

The Amboseli geospatial layers and the Word report template are downloaded automatically from Dropbox at run time — no additional setup is required for these.

Get started

New to the workflow? Start with the User Guide for a walkthrough of loading the template, connecting EarthRanger, and running it. Running into an error? Check Troubleshooting first.
